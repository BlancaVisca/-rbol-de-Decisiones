# Práctica – Clasificador con Árbol de Decisión

Este repositorio contiene el desarrollo de una práctica cuyo objetivo es implementar un **clasificador supervisado mediante un Árbol de Decisión**, aplicado a un conjunto de datos para tareas de clasificación.

El proyecto incluye una implementación en Python que permite entrenar el modelo, evaluar su desempeño, generar la matriz de confusión y visualizar el árbol obtenido, facilitando así el análisis e interpretación de las decisiones tomadas por el algoritmo.

## Funcionalidades principales

- Carga de archivos de datos de entrenamiento y prueba.  
- Entrenamiento del modelo mediante un Árbol de Decisión.  
- Generación de la matriz de confusión como evidencia de los resultados.  
- Cálculo de métricas de desempeño del clasificador.  
- Visualización del árbol de decisión obtenido.  
- Análisis e interpretación del comportamiento del modelo.
